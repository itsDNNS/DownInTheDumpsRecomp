# Host hooks in the recompiled code (host_hook(c, m, addr) runs before the original code).
#   <function name>          hook at the function entry
#   0x<address> <name>       hook before the instruction at that address
# WaitTimer: the game polls the 16 Hz timer in a busy loop (WaitFrameTime); the host sleeps there.
WaitTimer
# PlayFIL waits for the audio callback in a loop with a timeout of 40 million iterations, calibrated
# for 1996 CPUs; the host waits in real time instead.
0x2CA87 PlayFIL_WaitSound
# SubTitle: the automatic exploration (host/explore.cpp) notices the hint texts of the game, e.g.
# the one it shows while an object is held over a hotspot it can be used on.
SubTitle
# Gets: the text input of the game (the name of a saved game); the exploration types only into it.
Gets

# Fixes of bugs of the game itself (found by the automatic exploration; on DOS they ended in a page
# fault, see host_hook in host/machine.cpp):
# BlkRamInit frees all memory blocks at a scene change (and a load), but the inventory bar can still
# hold its work buffers BandeTempo and BandeTempoBis; hiding the bar then overwrote the new scene's data.
BlkRamInit
# MkBandeObj makes the bar's buffers anew on every call without freeing the previous ones.
0x2164C MkBandeObj_Bis
0x2170B MkBandeObj_Tempo
# Persp3D takes a character's frame as direction * phases + phase. Races in the game's scripts (a
# dialogue while a gag starts, a second click while the character speaks) can leave a one-direction
# animation (talking, gags) with another direction, which points past the end of its table.
0x25CE1 Persp3D_Frame
# The cause of those races: a gag or a dialogue started while another one ran on the same character
# and overwrote the saved normal animation (the character then walked with the gag or talking
# frames). The running one now ends first, the way the game ends it itself.
0x2266B PlaySpritGag_Start
0x22757 PlaySpritDlg_Start
# ScrutAllButtons tests the buttons at the pointer sprite's position plus its hotspot, but the sprite
# is kept on the screen: near an edge the click point was not where the mouse was. With the open
# hand as pointer (hotspot 33 pixels down) LOAD in the top bar could not be clicked at all.
0x12691 ScrutAllButtons_Spot
# The end of a gag (TokenGag) or of a FIL token (TokenFil) frees all memory taken from the top of
# the pools (FMem1 = Fin1, FMem2 = Fin2). An IPOV that started meanwhile keeps its tracks there;
# freeing them let the next sound overwrite them while the IPOV played. Its own end frees them.
0x24869 TokenGag_FreeTop
0x24BB9 TokenFil_FreeTop
0x24BC3 TokenFil_FreeTop2
# Fork starts a new script thread (the call of MoteurExec). Cartoon 1's slow-motion machine runs a
# forked loop that plays its animation every few seconds and clears a variable meanwhile; its button
# waits for that variable with the pointer hidden. A scene change during the animation killed the
# loop with the variable cleared, and the next press of the button waited forever.
0x181FB Fork_New
